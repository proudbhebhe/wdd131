HomeGoods

Site Purpose

The site provides details about appliances sold to civil servants in installments, showing different categories of products, customer testimonies and contact details.

Scenarios

scenario1:Which Television is best for me and my family?

Scenario2:Where is the physical shop located?

Color Schema

Primary Color: #003B90 (Royal Blue)

This color will be used for the header, navigation bar, and page headings.

Secondary Color: #07193D (Deep Navy Blue)

This color will be used for buttons, links, and other accent elements.

Typography

Fonts I will use

Ubuntu, Inter and sans-serif fallback

Ubuntu will be used in the header, Inter and sans-serif will be applied to all headings and paragraphs.
